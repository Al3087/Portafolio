HAND BRIDGE

Problem
Many people want to volunteer but do not know where or how to help. At the same time, organizations such as orphanages, shelters, and nursing homes need volunteers and support.
Process
We researched how this problem affects communities and looked for ways to connect people who want to help with organizations that need support. After that, my team and I worked together to create this project.
Solution
We created a website that connects people interested in volunteering with organizations that need help. Users can learn about upcoming volunteer opportunities and make donations through transfers if they wish. This website helps organizations receive support and connects them with people who want to make a difference.
Result
A functional website where users can explore different organizations, create an account, log in, and participate in volunteer activities.

DogVision

Problem
Nowadays, it can be difficult to identify different dog breeds just by looking at them. Sometimes, people confuse one breed with another. Also, not every image contains a dog.
Process
First, we trained an artificial intelligence model using Teachable Machine. We used six categories and created a website with HTML, CSS, and JavaScript.
Solution
Our solution is called DogVision. It allows users to recognize five dog breeds and other images using a webcam or by uploading a photo.
Result
As a result, we created a functional website that can recognize the six categories using artificial intelligence. It displays the predicted category and its confidence percentage. DogVision is an easy and interactive tool that helps people learn about technology and dog breeds.

The Internet Cloud

Problem
Many people do not know what cloud computing is, how it works, or how it can be useful in everyday life.
Process
I researched cloud computing to understand its main concepts, benefits, types, and services. Then, I organized the information into different sections and added tables and multimedia resources to make learning easier.
Solution
I developed an educational website that explains cloud computing in a simple and organized way. It includes information about cloud services, their advantages, different types, and useful resources for further learning.
Result
A functional educational website where users can explore information about cloud computing, compare data, and access multimedia resources to improve their understanding of the topic.
